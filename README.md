# License Plate Recognition
An application that can read license plate from images and display information about them.

This is a project for Artificial Intelligence course at International University, VNU-HCMC.

## Member
- Vũ Quốc Khánh - ITCSIU24039

## Technologies
- Python
- Pytorch
- Tensorflow

## Dependencies
- [uv](https://docs.astral.sh/uv/)

## Setup
1. Install required dependencies in [Dependencies section](#dependencies).

2. Inside this project directory, run:
    ```bash
    uv sync
    ```

    This will download project dependencies.
